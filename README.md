# SLOT2

Anbernic H700 계열 휴대기(RG SP, RG35XX/34XX/40XX 시리즈, RG CubeXX)를 위한 카트리지 은유 프론트엔드.
[BaseOS](https://github.com/pvaibhav/BaseOS) 위에서 동작하며, GB · GBC · GBA · NES · SNES · MD · SMS를
인프로세스 libretro 코어로 구동한다.

[brandonkowalski/slot](https://github.com/brandonkowalski/slot)(MIT)에서 출발해 완전히 재구성한 프로젝트.
