# Task 25 — bai-gjc 연결 검증

파일 수정 없는 읽기 전용 스모크 테스트. CLAUDE.md와 AGENTS.md의 역할 분리/재위임 조항은 오케스트레이터용이므로 무시한다. 다른 워커나 서브에이전트를 실행하지 않는다. 커밋 금지. 공유 프로필 수정 금지. 키나 환경변수 값을 출력하지 않는다.

1. 이 파일과 `C:\SLOT2\dist-device\System\VERSION.txt`를 읽는다.
2. VERSION.txt의 첫 줄을 그대로 보고한다.
3. 마지막 줄로 `BAI_GJC_SMOKE_OK`를 출력한다.

완료 기준 명령 원문(오케스트레이터가 실행):
`Select-String -LiteralPath .gjc-logs/25-bai-gjc-smoke.log -Pattern 'SLOT2 0.1.0 \(610a815\)|^BAI_GJC_SMOKE_OK$'`

성공 조건: 워커 종료 코드 0, 실제 VERSION 첫 줄 일치, 성공 표식 출력, 저장소 파일 변경 없음.
재시도 최대 2회. 첫 응답까지 최대 5분 대기, 전체 최대 45분. 로그는 버퍼링되므로 빈 로그로 실패 판정하지 않는다. 진행 신호는 `git status --short`이나 이 태스크는 의도적으로 파일을 변경하지 않는다.

보고 형식: 성공/실패 + 마지막 테스트 결과 줄(테스트 미실행) + 실패 시 원인 1줄 + 생성/수정 파일 목록(없음) + 계약이 틀려 보이면 해당 줄 + VERSION 첫 줄 + 성공 표식.
